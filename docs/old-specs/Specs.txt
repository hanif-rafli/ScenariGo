# High level usage flow:
1. User chooses snapshot of map where their operations take place.
2. User places store locations
2.1. User populates store inventory.
3. User places warehouse locations.
3.1. User populates warehouse inventory.
4. User fills in fleet information.

# Features: 
## Data Structures and algorithms:
- no dictionary
- Network flow, ford fulkerson, residual network [must have]
- Multigraph Dijkstra [must have]


##  Map snapshot:
what a 'map' includes:
- country shape
- major roads
- sea/air ports
- sea/air paths
- cargo train stations and railways. 


## Requirements (User POV)
- to choose a portion of map (topojson, etc.) so I can start planning fleet movement.
- to receive a report of what items need restocking at which store and optimally from which warehouse so that I can assign the fleet accordingly.
